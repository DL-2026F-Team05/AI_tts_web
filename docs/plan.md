# 계획

## 주제
딥러닝 기반 시각장애인 맞춤형 패키지 텍스트 및 정보 인식 시스템. 포장 사진에서 글자를 읽고, 소비기한·알레르기 성분 같은 핵심 정보를 우선순위대로 정리해 음성으로 알려 준다.

## 기획에서 정한 것
1. **OCR 앞에 영역 검출을 둔다.** 소비기한, 알레르기 표시란, 원재료, 제품명 영역을 먼저 찾고 잘라서 읽는다. 작은 글씨가 크게 들어가고, 항목별 F1·혼동행렬이 검출 클래스에서 나오고, Grad-CAM(EigenCAM)을 붙일 모델이 생긴다.
2. **모르면 모른다고 말한다.** 신뢰도가 낮으면 "다시 찍어 주세요"로 넘긴다. 위험 오분류는 두 숫자로 잰다.
   - 위험 놓침률: 실제로 지났거나 내 알레르기 성분이 있는데 안전하다고 안내한 비율
   - 보류율: 판단을 보류한 비율
   - 기준값을 바꿔 가며 두 숫자를 그린 그래프가 보고서의 핵심 그림
3. **소비기한 기준.** 소비기한 표시제는 2024년 1월 전면 시행, 냉장 우유류만 2031년 1월 1일부터 적용. 파서는 소비기한·유통기한 둘 다 읽는다. "별도표기일까지"는 다른 면을 찍으라고 안내한다.

## 역할과 입출력

| 담당 | 맡은 일 | 입력 → 출력 | 코드 |
|---|---|---|---|
| 이도현 | 데이터셋 확보·어노테이션, OCR 모델 | 사진 → 영역 목록, 글자 박스 목록 | `packreader/ocr/` |
| 배창현 | 이미지 전처리, 촬영 환경별 OCR 개선·비교 | 사진 → 품질 판정, 보정한 사진 | `packreader/preprocess/` |
| 이서영 | 핵심 정보 추출, 날짜 해석, 알레르겐 매칭, 위험 판단 | 글자 박스 → 항목, 위험도 | `packreader/extract/` |
| 박세준 | TTS, 웹 데모, 모듈 통합·테스트 | 항목 → 안내 문장, 음성, 화면 | `packreader/speech/`, `app/`, `pipeline.py`, `tests/` |
| 박주윤 | 보고서 | 평가 결과 → 보고서 | |
| 백연경 | PPT | | |
| 김세희 | 대본, 발표 | | |

촬영과 라벨링은 병목이라 1~2주차에는 7명이 나눠서 한다 (보고서·PPT·발표 담당 포함).

## 일정 (마감이 정해지면 날짜를 고친다)

| 주차 | 목표 | 끝났다는 기준 |
|---|---|---|
| 1주 (11/9~) | 뼈대, 약속, 촬영 시작 | 가짜 모듈로 사진→음성 한 바퀴 (완료), AI Hub 신청, 촬영 규칙 공유 |
| 2주 (11/16~) | 데이터, 기준 성능 | 제품 정답표, 기성 OCR 2종 CER, 날짜 파서 1차, TTS 엔진 확정 |
| 3주 (11/23~) | 모델 개선 | 영역 검출 학습, 인식기 파인튜닝, 전처리 비교, 데모에 실제 모듈 연결 |
| 4주 (11/30~) | 평가, 오류 분석 | 조건별 표, 위험 놓침률·보류율, Grad-CAM, 사용자 테스트 |
| 5주 (12/7~) | 마무리 | 보고서, PPT, 발표, 여유분 |

## 1주차 할 일

- **전원**: 집에 있는 식품 포장 10개씩 [data_guide.md](data_guide.md) 규칙대로 촬영, 정답표 작성
- **이도현**: AI Hub 실사 한글 OCR 데이터 신청(정확한 데이터셋 이름 확정), 코랩에서 EasyOCR·PaddleOCR 돌려 보기
- **배창현**: 촬영 조건(저조도·반사·흔들림·구김) 기준 정리, 품질 판정 기준값을 실제 사진으로 확인
- **이서영**: `tests/test_extract_spec.py`의 xfail 항목 살펴보고 우선순위 정하기
- **박세준**: 뼈대 레포, 코랩 노트북, TTS 엔진 비교 실험 준비

## 산출물과 기획서 항목 연결

| 기획서 항목 | 어디서 나오나 |
|---|---|
| CER, WER | `evaluation/run_eval.py` (글자 박스 정답이 있는 테스트셋) |
| Accuracy, Precision, Recall, Macro F1 | 알레르기 항목별 F1, 영역 검출 P/R, 날짜 정확도 |
| 위험 오분류 | 위험 놓침률, 틀린 날짜를 말한 비율, 날짜를 지어낸 비율 |
| 클래스별 성능, 혼동행렬 | 영역 클래스별 혼동행렬, 알레르기 성분별 tp/fp/fn |
| 일반화 성능 | 촬영 조건별 표 (파일 이름의 조건으로 자동 분류) |
| 설명 가능성 | 영역 검출기에 EigenCAM |
| 사용자 테스트 | 웹 데모의 첫 음성까지 시간 기록(`logs/events.jsonl`), 설문 |
| 데모 | `app/` 웹 데모 |
