# data

| 폴더 | 내용 | 깃에 올리나 |
|---|---|---|
| `samples/` | 합성 샘플 사진 6장과 정답 JSON (지어낸 제품) | 올림 |
| `templates/` | 정답표 양식 | 올림 |
| `splits/` | 제품 ID 목록 (train/val/test.txt) | 올림 (모두 같은 분할을 쓰려고) |

실제 촬영 사진과 라벨은 팀 드라이브에 둔다. 구조와 규칙은 [docs/data_guide.md](../docs/data_guide.md).

샘플 다시 만들기: `python -m tools.make_samples`

| 샘플 | 상황 | 확인하는 것 |
|---|---|---|
| S001 | 과자 뒷면 | 정상 흐름, 함유와 혼입 구분 |
| S002 | 푸딩 뒷면 | 소비기한 지남 → 위험 |
| S003 | 두유 뒷면 | '별도표기일까지' → 다른 면 안내 |
| S004 | S001을 흔들리고 어둡게 | 다시 찍기 안내, 판단 보류 |
| S005 | 바닥에 점 글씨로 찍힌 날짜 | 종류 모르는 날짜 |
| S006 | 우유 팩 | 유통기한 표기 (우유류는 2031년부터 소비기한 적용) |
